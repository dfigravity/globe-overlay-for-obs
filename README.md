# Globe Overlay for OBS

An OBS Studio source that shows a live viewer check-in globe (Triode check-in)
with 28 selectable looks, every visual setting exposed as OBS properties
(sliders, toggles, colour pickers), and the streamer's Triode link entered
once in the source's settings. No local server: the looks ship inside the
plugin and load through obs-browser.

Status: **source complete, not yet compiled.** Built from
[obs-plugintemplate](https://github.com/obsproject/obs-plugintemplate).

## Layout

- `src/plugin-main.c` — module entry; registers the source in `obs_module_post_load`
  only if obs-browser's `browser_source` exists.
- `src/globe-source.c` — the `globe_overlay_source` type: wraps a private
  `browser_source`, builds `http://absolute/<look>.html?settings=<json>&channel=…`,
  pushes live changes with the `javascript_event` proc, debounces structural
  changes, forwards Interact mouse/keyboard to the page, generates the property
  sheet from `globe-schema.h`.
- `src/globe-schema.h` — GENERATED by `../tools/gen-schema-c.mjs` from the web
  project's `static/wild/tweaks-schema.js`. Do not edit.
- `data/looks/*.html`, `data/looks/manifest.json` — GENERATED by
  `../tools/build-obs.mjs --all` + `../tools/sync-plugin-data.sh`.
- `data/locale/en-US.ini` — UI strings.

## Quick local test build (this Mac, no Xcode)

`./build-local-macos.sh --install` compiles with the command line tools against
the libobs inside /Applications/OBS.app (headers for the exact OBS version in
`~/.local/opt/obs-headers`, simde in `~/.local/opt/simde-0.8.2`), builds an
ad-hoc-signed `.plugin` under `~/Library/Caches`, and copies it to
`~/Library/Application Support/obs-studio/plugins/`. Restart OBS afterwards.
CMake 4.4 + Ninja are installed in `~/.local/bin` for the template path later.

## Build (release, template)

Prerequisites (macOS): Xcode 16, CMake ≥ 3.30 (`brew install cmake`).

```sh
cmake --preset macos
cmake --build --preset macos --config RelWithDebInfo
```

Output: `build_macos/RelWithDebInfo/globe-overlay-for-obs.plugin` → copy to
`~/Library/Application Support/obs-studio/plugins/`. Windows: `cmake --preset windows-x64`
with Visual Studio 2022; Linux: `cmake --preset ubuntu-x86_64`.

CI: the template's GitHub Actions build all three platforms on push; tagging
`v0.1.0` produces a draft release with installers. macOS notarisation needs
the signing secrets described in the OBS Codesigning wiki.

## Packaging (macOS, this machine)

`./package-macos.sh` → `release/globe-overlay-for-obs-<version>-macos-arm64.zip`
(the bundle) and `...-macos-arm64.pkg` (installer into the user's
`~/Library/Application Support/obs-studio/plugins`). Both are **ad-hoc signed**:
they work on this Mac, and testers can install the .pkg with right-click → Open.
Shipping publicly the way obs-shaderfilter does needs an Apple Developer ID
($99/yr) for signing + notarization, and the template CI for the universal
(arm64+x86_64) macOS build, the Windows zip/installer and the Linux .deb.

## Release checklist (public)

1. Push this folder to GitHub (`alderosh/globe-overlay-for-obs`); CI builds all platforms on push.
2. Add repo secrets from the OBS Codesigning wiki (Developer ID cert, notarization API key).
3. `git tag v0.1.0 && git push --tags` → draft GitHub release with installers.
4. Forum resource page at obsproject.com/forum/resources (OBS Studio Plugins).
5. Blockers in ../PLUGIN-PLAN.md: Triode permission, empty default channel (done), licences.
